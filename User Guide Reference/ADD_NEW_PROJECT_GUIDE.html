📁 Add New Project — Developer Guide

Step-by-step reference for adding projects to the portfolio

src/components/Projects.tsx
STEP 1 Project Object — All Fields

Each project is one object inside the projects array in Projects.tsx. The full shape is:

// Minimal — no video, no badge
{
  title      : 'Your Project Name',          // REQUIRED
  subtitle   : 'Short one-line tagline',       // REQUIRED
  description: '2-3 sentence project description.', // REQUIRED
  tech       : ['Python', 'React', 'FastAPI'],   // REQUIRED — array of strings
  category   : 'Machine Learning',            // REQUIRED — must be exact string (see Step 2)
  github     : 'https://github.com/C-Logesh-Perumal-29/repo', // REQUIRED
  demo       : '#',                          // REQUIRED — use '#' if no live demo
  featured   : false,                        // REQUIRED — true = large featured card
  badge      : 'New',                        // OPTIONAL — small label shown on card
  gradient   : 'from-sky-500 to-blue-600',   // REQUIRED — Tailwind gradient (see Step 3)
  videoEmbed : 'https://www.linkedin.com/embed/feed/update/urn:li:ugcPost:XXXXXXXXX?compact=1',
                                              // OPTIONAL — LinkedIn embed src (opens video popup on Demo click)
},
FieldTypeRequired?Notes
titlestringRequiredProject name shown on card header
subtitlestringRequiredOne-line tagline shown below title
descriptionstringRequired2–3 sentences; grid cards clip at 3 lines
techstring[]RequiredGrid cards show first 5; overflow shown as "+N more"
categoryCategoryRequiredMust exactly match one of the 5 allowed strings
githubstring (URL)RequiredFull GitHub repo URL
demostring (URL)RequiredUse '#' if no live link. Ignored when videoEmbed is set
featuredbooleanRequiredtrue → large featured card (always visible). false → filterable grid card
badgestringOptionale.g. '93.5% Accuracy', 'Real-time', 'AI-Powered'
gradientstringRequiredTailwind gradient classes — see Step 3 for ready-to-use values
videoEmbedstring (URL)OptionalLinkedIn embed src. When present, Demo button opens inline video popup instead of navigating
STEP 2 Available Categories

The category field must be one of these exact strings (case-sensitive):

Generative AI Computer Vision Machine Learning Automation Full Stack
💡 Machine Learning category exists in the code but has no projects yet — it is ready to use.

To add a brand-new category (e.g. 'Data Science'), update 3 places in Projects.tsx:

// 1. Add to the type (line ~258)
type Category = 'All' | 'Generative AI' | 'Computer Vision' | 'Machine Learning'
               | 'Automation' | 'Full Stack' | 'Data Science'  // ← add here

// 2. Add colour style to categoryStyle object (line ~365)
'Data Science': 'bg-sky-50 dark:bg-sky-900/30 text-sky-700 dark:text-sky-300 border-sky-300 dark:border-sky-700',

// 3. Add to CATEGORIES array (line ~374)
const CATEGORIES: Category[] = ['All', 'Generative AI', 'Computer Vision',
  'Machine Learning', 'Automation', 'Full Stack', 'Data Science']  // ← add here

STEP 4 Getting the LinkedIn Video Embed URL

When a project's Demo should open a video popup instead of redirecting:

  1. Open your LinkedIn post in a browser.
  2. Click the ⋯ (More options) menu on the post.
  3. Select Embed this post.
  4. Copy only the src value from the <iframe> tag:
    // Full iframe LinkedIn gives you:
<iframe src="https://www.linkedin.com/embed/feed/update/urn:li:ugcPost:XXXXXXXXX?compact=1"
        height="399" width="504" ...></iframe>

// Only paste the src value into videoEmbed:
videoEmbed: 'https://www.linkedin.com/embed/feed/update/urn:li:ugcPost:XXXXXXXXX?compact=1',
  5. Set demo: '#' — it is ignored when videoEmbed is present.
⚠️ If you do not have a LinkedIn video, simply omit the videoEmbed field entirely. The Demo button will then use the demo URL as a normal external link.

STEP 6 Where to Insert in the File 
const projects: Project[] = [

  // ── FEATURED ─────────────── paste featured projects here (featured: true)
  { ... },
  { ... },

  // ── GRID ─────────────────── paste non-featured projects here (featured: false)
  { ... },   // ← add your new project here

]
  • Append featured cards inside the // ── FEATURED block.
  • Append grid cards inside the // ── GRID block.
  • Order within each block controls display order on the page.
